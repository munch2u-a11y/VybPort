Standard adaptor

vybport.arena/1

Every entry runs through the same adaptor, so no build gets a bespoke harness. VybPort passes your run command a fixture path and an output path; the command writes back exactly one JSON object.

your-runner --fixture {fixture} --out {output}

# {output} (or stdout) must contain:
{
  "adaptor": "vybport.arena/1",
  "score": 84.0,
  "detail": { "anything": "you want on the record" }
}

Preflight runs your command against the public sample fixture and costs nothing. Only once every check passes does VybPort spend your ticket and run the held-out fixture.
